# West Pacific Bridge

Marketing site for West Pacific Bridge — US sales and brand operations for Chinese
manufacturers, and direct factory sourcing for American businesses.

- Single-file static site: `index.html` (no build step, no dependencies)
- Bilingual English / 简体中文 with an in-page toggle (148 strings), persisted to
  `localStorage` and auto-selected from the visitor's browser language
- Fonts: Geist + Noto Sans SC via Google Fonts

## Local preview

Any static server works, for example:

```
npx serve .
```
